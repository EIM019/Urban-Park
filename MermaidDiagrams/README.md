# Mermaid Diagrams for Carpark Management System

This folder contains editable Mermaid files for the project.

Files:

- `erd.mmd` — Entity Relationship Diagram for the main domain model
- `system-architecture.mmd` — High-level architecture of the ASP.NET Core MVC app

How to use:

1. Open either `.mmd` file in a Mermaid editor or Mermaid Live Editor.
2. Edit nodes, labels, or relationships directly.
3. Save the file and preview the diagram.

If your Mermaid app only supports Markdown, copy the contents into a Markdown code block:

```markdown
```mermaid
...diagram...
```
```
